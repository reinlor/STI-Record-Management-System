# Web-based Record Management System from the Guidance Office of STI College Dasmarinas
This web-system is made using Firebase, Express, React, Node (FERN Stack). It is made to automate and simplify processes of the Guidance Office of STI College Dasmarinas Cavite. It uses hybrid setup of fetching and manipulating data from the firebase, it uses firebase onSnapshot to fetch real-time modification and uses express.js for writing operations. The express setup follows an MVC like Structure (leaving the 'views' part😏) where as models, controllers, and routes are separated for increased readability and scalability.
